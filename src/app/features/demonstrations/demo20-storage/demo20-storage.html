Démonstration 20 - Le Storage

Comparaison entre LocalStorage et SessionStorage:

Caractéristique LocalStorage SessionStorage
Durée de vie Persiste jusqu'à suppression manuelle Effacé à la fermeture de l'onglet
Capacité ~5-10 MB ~5-10 MB
Partage entre onglets Oui Non
Synchronisation Tous les onglets du domaine Un seul onglet
Type de données Chaînes uniquement (JSON possible) Chaînes uniquement (JSON possible)

Méthodes:

Méthode Description Exemple
setItem(key, value) Ajoute ou modifie une paire clé-valeur localStorage.setItem('nom', 'Jean')
getItem(key) Récupère la valeur associée à une clé localStorage.getItem('nom')
removeItem(key) Supprime une paire clé-valeur localStorage.removeItem('nom')
clear() Vide complètement le stockage localStorage.clear()
key(index) Récupère la clé à un index donné localStorage.key(0)
length Nombre de paires clé-valeur stockées localStorage.length
Sérialisation d'objet Stocker et récupérer des objets en JSON localStorage.setItem('user', JSON.stringify({{ '{' }} id: 1, nom: 'Jean' {{ '}' }})) JSON.parse(localStorage.getItem('user'))

Les préférences sont sauvegardées dans le localStorage : elles persistent même après fermeture du navigateur.
